# Online Library System

A React + Redux based Online Library System where users can browse books, search books, filter by categories, view details, and add new books dynamically.

---

# Features

- Home Page with popular books
- Browse Books page
- Search books by title or author
- Filter books by category
- Dynamic category routing
- Book Details page
- Add new books dynamically
- Redux state management
- Responsive Navbar
- Custom 404 Page
- Skeleton loading effect
- Tailwind CSS styling

---

# Tech Stack

- React JS
- Redux Toolkit
- React Router DOM
- Tailwind CSS
- Vite

---

# Installation Steps

## Clone Repository

```bash
git clone YOUR_GITHUB_REPOSITORY_LINK
```

## Move into project folder

```bash
cd Online-Library-System
```

## Install Dependencies

```bash
npm install
```

## Start Development Server

```bash
npm run dev
```
